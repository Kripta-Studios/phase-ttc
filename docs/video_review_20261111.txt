implementation and saved evidence. The video needs scientific-summary and
diagram corrections before it can represent the current paper in full.

   The displayed MAE 0.825 -> 0.336 s is real, but uses organizer-style offline
   interpolation of negative outputs. It is not raw signed runtime MAE.
   Use 0.824 -> 0.347 s for the primary 434-query signed comparison, or label
   the older numbers explicitly as offline-interpolated scores.
   Add the current matched-head result: no consistent benefit from event access
   or phase versus inverse-TTC on the inspected transfer cohort.
   Add the geometry result: fixed mixture/router common-support MAE 0.289/0.304 s;
   road-only MAE 0.221/0.159 s. The road comparison favors routing, while the
   pooled difference interval includes zero. Avoid attributing the complete
   benchmark gain to a uniquely superior phase/event interface.
   Replace the outdated paper-edition footer with the current paper link.

2. 01:13-01:35: complete the A5 diagram connections.
   Pooled features and the pair token lack clear output paths. The foreground
   stage should show its dependency on encoder features, rather than leaving
   a raw-image arrow that can imply a decoder bypassing the encoder.

3. 01:35-01:50: complete the coarse-to-fine routing diagram.
   Both fine and coarse estimates must feed the weighted blend. The current
   outgoing arrow comes from the coarse side and terminates between boxes.
   Show the router weight feeding the blend separately from the two estimates.
   The formula w*fine + (1-w)*coarse and search dimensions are correct.

4. 02:05-02:23: correct the temporal-refiner layout.
   Connect the causal history and feature inputs to both modality GRUs.
   Move the RGB/Event state captions below the bars with clear spacing.
   Current captions overlap the lower bar area. Keep the existing indication
   that these bars are schematic, not measured hidden activations.

5. 02:23-02:40: draw the residual anchor explicitly.
   Connect the MLP correction and the raw RGB anchor to the addition operation.
   Keep the anchor distinct from the policy-clamped emitted RGB TTC.
   The 20-input, 32/32-hidden, three-output, 1,955-parameter head is correct.
   If width outputs are explained, include their RGB width-logit anchors and
   positive transform; two outputs alone are not calibrated confidence intervals.

6. 03:11-03:26: separate router inputs, weights and expert estimates.
   The four expert values need direct paths into the inverse-TTC blend, with
   quality features going to the router and learned weights going to the blend.
   The existing diagram sends experts toward the router but omits their direct
   value paths. Three-router averaging in seconds is correctly described.

7. 00:00-00:11: correct the recording count.
   'Follow one real recording' conflicts with the two recordings used across
   the video. Use 'Follow real recordings through the prediction pipeline.'
