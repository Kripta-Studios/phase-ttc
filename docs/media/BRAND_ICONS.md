# Brand icons

GitHub and LinkedIn PNGs are rendered from the corresponding Font Awesome 5 Free brand glyphs, using the installed `fontawesome5` LaTeX package. Font Awesome Free icons are licensed under [CC BY 4.0](https://fontawesome.com/license/free). GitHub uses #181717; LinkedIn uses #0A66C2. Their names and marks belong to their respective owners.

The existing Hugging Face PNG retains its original official artwork. Each icon links to the corresponding project or author page.
