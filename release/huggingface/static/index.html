What can you reproduce?

Inference and saved evaluation

Download the exact checkpoints, normalizers, runtime and examples. The inference script checks SHA-256 hashes. A second command recalculates the corrected 460-query transfer metrics from saved predictions and public target associations.

Training

The adapted bundle includes fit features and a fixed trainer. Reproduction matched all three router state dictionaries exactly. Full original training needs the external datasets and reconstruction of historical caches; its source and recipe are included.

Live interactive inference

A working Gradio app is included in gradio_app.zip. Extract it, install its requirements and run python app.py. Hosting this Python app on Hugging Face requires an account plan with compute access. This static page has no upload service.

Sensor and deployment requirements

Both models expect calibrated event/RGB observations and supplied object regions. An autonomous detector and calibrated uncertainty are separate work. The paper's 29.14 ms p95 replay exceeds a 20 ms budget.
