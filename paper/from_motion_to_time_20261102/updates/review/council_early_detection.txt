EDITORIAL VOTE
Treat detection as a separate supplementary experiment and engineering bridge, not as the core PHASE-TTC accuracy result. The strongest early finding is a controlled, TRAIN-fitted fixed-proposal quality ranker. A second useful result is failed promotion of temporal/event fusion under prespecified small screens. EVALUATION AND CAUSALITY LESSONS
Original pilot GT passed through training filters: retained 829/1565 train, 938/1936 selection annotations. Revised v2 independent GT includes 1035 selection objects plus 901 depth-ignored (same 256 frames). Preserve legacy and revised denominators separately. New v2 AP .019821723110847754, constant TRAIN prior .003839390946110635, fixed derangement .003654753769763242; only 2 sequence clusters, so bootstrap evidence is weak. Raw public selection eventually requires another alignment handled by parent.
Public raw dataset audit: 40 train sequences, 118247 train frames; 12 test/35940 test frames. Train list46 vs release40 discrepancy is not new usable diversity. 24/8/8 train/selection/calibration split has no certified acquisition-group independence.
Sensor-time causal RGB history requires past exposure end <= current exposure start; current image only available at its exposure end. Event input [exposure_end-50ms, exposure_end). Arrival/transport clocks absent, so no physical latency claim. Garl label timestamps differ from exposure clocks; no constant offset can be assumed (sampled 40/40 sequences vary). Shared RGB media do not prove identical object annotation IDs. Same literal object ID had 0/36 exact corner correspondences in audit; closest neighbor is not an authorized GT join.
Exposure contamination: frozen TRAIN40 PHASE producers already saw all 40 sequences. Holding out detection sequences does not create independent detection+tracking+TTC evaluation. Independent TRAIN24 foundation/teacher crosswalk and E_A5 CPU backward exist, but no independent production refit was trained in these docs. A5 historical loss is supervised, including TTC and bbox terms plus relational distillation, not SSL.

PORT / PILOT CAVEATS
Portable MonoDGP is an adapted variant with PyTorch grid_sample attention and fixes (group_num, depth scaling, fx->fy, empty targets, finite matching). No equality with the original custom CUDA extension was measured; it did not compile locally. Exact label-free inference parity measured 272 frames (16 train+256 selection), not 279 (seven temporal frames lack comparison reference).
Original pilot velocity head L2: .5949011525138365 vs zero1.3811502059018668 vs train-mean .7591277457551672 m/s on same 401 matches. Second component worsens (.03088006 vs .02086/.02062); conditional native-label affinity, not physical relative velocity, AVE or TTC.
Engineering optimizations are not science claims: AP101 exact envelope, streaming serializer, bounded prefetch/input cache, explicit resume. B2/B4 inference had numerical failures relative to B1 and were rejected despite faster throughput. GPU time, startup, prep and end-to-end latency must stay separate.
